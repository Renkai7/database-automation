## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → developer workstation | Third-party package code is downloaded and executed at install time on the machine that will hold the development database |
| host network interfaces → development PostgreSQL container | Anything that can reach the published port gets the development role's full privileges (D-17: one role) |
| working tree → git remote | Anything written into a tracked file leaves the machine permanently |
| container init path → database schema | Any mechanism that writes schema outside the migration path is an ungated route into the database |
