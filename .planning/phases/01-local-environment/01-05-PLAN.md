development database, so the edge is declared rather than the pair run in parallel. Running after
01-04 also gives this plan the strongest possible fixture: a freshly rebuilt, fully migrated,
deterministically reseeded database.

Purpose: APP-01 requires the application to boot against the schema; the fixture earns its keep only
if the screen actually renders the schema's relationships, which is what makes later phases' schema
churn (a dropped column the screen reads, an expand-and-contract rename) genuinely dangerous rather
than academic. The other three screens stay unported (D-07).

Output: the wired Recipe Page, its not-found and error paths, and a smoke test that proves seeded
content reached the browser.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser request → Next.js Server Component | The `slug` route segment is caller-controlled input that reaches a database query |
| server-side error → rendered error page | Anything the error boundary renders is visible to whoever loaded the page |
| database rows → rendered HTML | Seeded text is interpolated into the page and could carry markup |
| design tree → shipped bundle | The design directory contains a runtime and three unported screens that must not leak into the build |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

| T-01-21 | Information Disclosure | `error.tsx` output | high | mitigate | The boundary renders fixed copy and a retry button only; it does not render `error.message` or `error.stack`, either of which can carry connection details. The smoke test exercises a production build, where framework stack traces are not sent to the client |
| T-01-22 | Tampering | seeded row text rendered into HTML | low | accept | React escapes interpolated text by default and no component uses a raw-HTML injection prop; the seed content is committed and deterministic, with no user-supplied path into it in this phase |
