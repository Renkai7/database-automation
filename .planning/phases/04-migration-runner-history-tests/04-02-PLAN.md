<objective>
Teach the analyzer two new observables and widen the code floor to cover the second one:
`transactionHostile` (D-10 — the statements PostgreSQL forbids inside a transaction block) and
`disarmsTimeout` (D-17 — a migration turning off its own safety rail). The floor's stated
definition widens from "irreversible data loss" to "irreversible data loss or self-disarming",
recorded as a principle rather than as a list that grew an unexplained member.

Purpose: the runner's wrap-or-unwrap decision (plan 04-04) must read the analyzer's fact
vocabulary, not keep a second keyword list that would drift — the split `03-CONTEXT.md` D-11's
pure-core seam exists to prevent. And a migration that disables `lock_timeout` is
architecturally identical to a rules file downgrading `DROP TABLE`: same shape, same answer.
Output: two new facts, seven new inspector branches, a widened non-weakenable floor, the rule
rows that express it, a matched adversarial pair proving nested coverage, and the decision
record.
</objective>
