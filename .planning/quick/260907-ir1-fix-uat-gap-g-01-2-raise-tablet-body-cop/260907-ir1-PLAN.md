  Work ONLY inside the `@media (min-width: 834px)` block (currently lines 390-508, ending at

  **Read the danger first.** The values `14px`, `13px`, `15px`, `14.5px`, `12.5px` and `16px`
  each appear in BOTH the 834px tablet block and the 1440px desktop block. This has been
  confirmed against the file. A value-based find-and-replace, a `sed` on a bare value, or a
  `replace_all` edit WILL corrupt the desktop block and violate D-3. Every single edit must be
  anchored to its selector within the tablet block - either by using the selector line plus its
  declaration as the unique match string, or by bounding the operation to the tablet block's
  line range. Prefer selector-anchored single edits; make them one at a time.

  **Part A - change 11 existing declarations.** Each row is an existing `font-size` inside the
  tablet block; change only the number.

  | Selector (inside 834px block) | From | To |
  |---|---|---|
  | `.rp-subtitle` | 14px | 16px |
  | `.rp-meta-item` | 14px | 15.5px |
  | `.rp-stepper-btn` | 16px | 17px |
  | `.rp-stepper-count` | 14px | 15px |
  | `.rp-tab` | 14px | 15.5px |
  | `.rp-ing-chip` | 13px | 14px |
  | `.rp-ing-name` | 15px | 16.5px |
  | `.rp-ing-qty` | 13px | 14px |
  | `.rp-step-num` | 14px | 15px |
  | `.rp-step-text` | 14.5px | 16.5px |
  | `.rp-step-timer` | 12.5px | 13.5px |

  Note the near-miss selector pairs: `.rp-tab` is not `.rp-tabs`, `.rp-step-num` is not
  `.rp-step`, `.rp-cta` is not `.rp-cta-wrap`. Match the selector line exactly, brace included.

  **Part B - add 2 tablet overrides.** These two selectors have no tablet `font-size`, so they
  are stuck at their phone size on tablet.

  - `.rp-servings-label` (phone base 12px) has NO rule at all inside the tablet block. Add a
    new rule declaring `font-size: 13.5px;`. Place it adjacent to the other meta-row rules -
    directly after the tablet `.rp-meta-icon` rule and before the tablet `.rp-stepper` rule -
    so it sits where a reader expects it. Use the same two-space indentation as its neighbours.
  - `.rp-cta` (phone base 14.5px) already HAS a tablet rule containing `width: 280px;` but no
    font-size. Add `font-size: 16px;` as a second declaration inside that existing rule rather
    than creating a duplicate rule.

  Total: 11 modified declarations + 2 added declarations = 13 changes, all inside the 834px
  block. Do not touch `.rp-title`, do not touch anything before line 390, and do not touch the
  1440px block.

  The Next.js dev server is already running on http://localhost:3000 serving
  /recipes/chicken-rice-bowl. CSS hot-reloads; no rebuild and no restart is needed.
  </action>
