- Added `escapingRelativeImports(filePath, source)`, a pure helper using `node:path`'s posix API to resolve relative imports against a file's directory and report every specifier that resolves outside `packages/automation/` — proven via a synthetic-input-only self-check (WR-04: no real source file mutated to prove the detector).
- Added `KNOWN_PACKAGE_BOUNDARY_ESCAPES`, a frozen inventory of the four existing `scripts/log.ts` escapes (`cli.ts`, `inspector/inspect.ts`, `inspector/inspect-plpgsql.ts`, `runner/run-migrations.ts`), and a guardrail test comparing the live scan to it by exact equality in both directions — no file is exempt, and a broken detector cannot pass vacuously since the expected state is non-empty.
- Recorded D25 in `docs/decisions.md`, stating explicitly that this closes the audit's single integration defect as *containment*, not removal, with the four escapes staying open debt routed to Phase 7's package extraction (PLAT-01).
